## Software Development Environment Setup Planning

**Student:** Aayan Bhandari


### 1. Project Scenario
I chose to build a simple business website. The website will have a homepage, business information, pictures, services, and a contact form. I will use HTML for the page structure, CSS for design, and JavaScript for basic interactive features.

### 2. Development Environment Planning

**IDE: Visual Studio Code (VS Code)**

I would use VS Code because it is free, easy for beginners, and works on Windows and Mac. It supports HTML, CSS, and JavaScript. It also has useful extensions and a built-in terminal.

**Additional Tools**
- Git: To track changes and restore previous versions of the project.
- GitHub: To store the project online and share code.
- Google Chrome: To test the website and inspect errors with Developer Tools.
- Live Server extension: To preview local website changes quickly.
- Figma (optional): To plan the website's layout before coding.

**Hardware Requirements**
- Computer: MacBook Air (Apple M1)
- RAM: 8 GB (sufficient for a simple website)
- Storage: 256 GB SSD, with enough free space for the tools and project files
- Operating System: macOS Ventura 13.1
- Internet: Needed to download tools and use GitHub

**Team Collaboration Plan**
The original exercise is designed for two students. Since I do not have a partner, I will complete the planning independently. In a team, I would use GitHub to share files, create branches for different features, and review changes through pull requests. Team members could divide tasks such as HTML structure, CSS styling, and testing.

**Estimated Setup Time and Complexity**
- Download and install VS Code: 10–15 minutes
- Install and configure Git: 10–15 minutes
- Create GitHub repository: 5–10 minutes
- Install Live Server: 5 minutes
- Create project folders and test setup: 10–15 minutes
- Total estimated time: 40–60 minutes

Complexity: Easy to moderate. The main challenge for beginners would be learning Git commands and connecting the project to GitHub.

### 3. Step-by-Step Installation Checklist

- [ ] 1. Check that the computer has enough storage and an internet connection.
- [ ] 2. Visit https://code.visualstudio.com and download VS Code for macOS.
- [ ] 3. Install VS Code and open the application.
- [ ] 4. Install Git using the appropriate installation method for macOS.
- [ ] 5. Open Terminal and enter `git --version` to verify Git is installed.
- [ ] 6. Sign in to GitHub or create an account.
- [ ] 7. Create a GitHub repository for the business website project.
- [ ] 8. Create a local project folder named `business-website`.
- [ ] 9. Open the project folder in VS Code.
- [ ] 10. Create `index.html`, `style.css`, and `script.js`.
- [ ] 11. Install the Live Server extension in VS Code.
- [ ] 12. Open `index.html` using Live Server and check it in Chrome.
- [ ] 13. Initialize Git, connect the repository, and make the first commit.
- [ ] 14. Push the project to GitHub and verify the files appear online.
- [ ] 15. Test the website layout and contact form on different screen sizes.

### 4. Conclusion
VS Code, Git, GitHub, Chrome, and Live Server would provide a suitable environment for building a simple business website. These tools are free, work on my MacBook, and support coding, testing, and version control. The setup would be manageable for a beginner and could also support collaboration if a team member became available.
