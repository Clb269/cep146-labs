**1. Based on your CPU cores, how many tasks can your processor theoretically handle simultaneously?**

My MacBook Air has an Apple M1 processor with 8 CPU cores. This means it can theoretically handle 8 processing tasks at the same time, with one task running on each core. The operating system can also switch between tasks quickly, allowing me to use multiple applications.

**2. Is your storage primarily HDD or SSD? What are the performance implications?**

My MacBook Air uses SSD storage. SSDs are faster than HDDs because they don't have moving parts. This helps my MacBook start faster, open applications quickly, and transfer files more efficiently.

**3. How does your RAM amount compare to typical requirements for modern applications?**

My MacBook Air has 8 GB of RAM. It is enough for everyday activities such as browsing, Microsoft Word, and basic programming using VS Code. However, 16 GB or more would be better for demanding applications, video editing, or running many applications at once.
