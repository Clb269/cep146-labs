## Exercise 1: License Detective

I researched five machine learning projects on GitHub and compared their software licenses.

| Project | License | Commercial Use | Attribution Required | Modify and Redistribute | Special Requirements |
|---|---|---|---|---|---|
| OpenAI Whisper | MIT | Yes | Yes | Yes | Must keep the original copyright and license notice. |
| TensorFlow | Apache 2.0 | Yes | Yes | Yes | Must keep required notices and mention changes. Also includes patent protection. |
| Scikit-learn | BSD 3-Clause | Yes | Yes | Yes | Must keep copyright notices and cannot use the creators' names for endorsement without permission. |
| Ultralytics YOLO | AGPL 3.0 | Yes, with conditions | Yes | Yes, with conditions | Must follow AGPL source-sharing rules. An enterprise license is also available. |
| mlpack | BSD 3-Clause | Yes | Yes | Yes | Must keep copyright notices and cannot falsely claim endorsement. |

### GitHub Repository Links

1. OpenAI Whisper: https://github.com/openai/whisper
2. TensorFlow: https://github.com/tensorflow/tensorflow
3. Scikit-learn: https://github.com/scikit-learn/scikit-learn
4. Ultralytics YOLO: https://github.com/ultralytics/ultralytics
5. mlpack: https://github.com/mlpack/mlpack

### Comparison

From my research, I learned that MIT, Apache, and BSD licenses give developers more freedom to use and modify software. Apache also provides patent protection. AGPL is stricter because it requires sharing source code in certain situations. I think MIT and BSD are easier to use for projects that need fewer restrictions.

## Exercise 2: Build Your Own License

# EmotionText AI Model – Custom License

**Version 1.0**

**Copyright © 2026 Aayan Bhandari**

### 1. Who Can Use the Model?

Anyone can use the EmotionText AI model, including students, teachers, researchers, and businesses.

### 2. What Are Users Allowed to Do?

Users are allowed to:

- Use the model for personal, educational, or commercial purposes.
- Modify and improve the model.
- Share and redistribute the model.
- Include the model in their own projects.

### 3. What Must Users Do?

Users must:

- Give credit to the original creator.
- Keep the copyright notice and license.
- Mention any changes they make to the model.
- Follow applicable laws when using the model.

Users are encouraged to share improvements, but it is not required.

### 4. What Are Users Not Allowed to Do?

Users cannot:

- Claim that they created the original model.
- Remove the original copyright information.
- Use the model for illegal activities.
- Falsely claim that the original creator supports their product.

### 5. What Happens If Someone Breaks the License?

If someone breaks the license rules, they will receive a notice and have 30 days to fix the problem. If they do not correct it, their permission to use and distribute the model will end.

The model is provided without a warranty, and the creator is not responsible for inaccurate predictions or resulting damages, as far as the law allows.

### Explanation of My License Choices

I chose these rules because I want people to use and improve the AI model without too many restrictions.

I allowed commercial use because businesses might find the model useful. I also allowed modifications so developers can improve it.

I made attribution necessary because the original creator should receive credit. I did not make sharing improvements compulsory because I wanted to give users more freedom.

I included restrictions against illegal use and false ownership to protect the creator. The 30-day warning gives users a chance to correct mistakes before losing permission.

I think this license provides a good balance between allowing people to use the model and protecting the original creator.
